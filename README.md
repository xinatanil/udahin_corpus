# Цель проекта
Структурирование и разметка кыргызско-русского словаря Юдахина для повышения удобства чтения, поиска и навигации по словарным статьям.
В качестве основы взята электронная версия словаря 2008-го года.

Превью: https://xinatanil.github.io/udahin-web/

## Альтернативы
На данный момент все (известные мне) онлайн-версии словаря (вроде el-sozduk.kg) используют вышеупомянутую электронную версию словаря. Однако, у нее есть ряд недостатков (в виде ошибок сканирования и отсутствия маркировки), которые данный проект пытается исправить.
Также существует 3-е издание словаря («Полиграфбумресурсы», Бишкек, 2019) в электронном PDF-формате с возможностью поиска по тексту.
Помимо них, в сети есть отсканированное 2-ое издание, но в виду низкого качества, ее можно вообще не рассматривать.

## Целесообразность проекта
Данный проект в качестве основы использует второе издание словаря 1965-го года (которое было оцифровано в 2008-ом), потому что оно предоставляло удобное разделение по словарным статьям (хоть и со своими минусами). Но есть вероятность, что проще всего было бы взять вышеупомянутое 3-е издание словаря и попытаться с помощью AI распарсить PDF (благо, качество позволяет), но эта мысль пришла мне в голову слишком поздно 🤦‍♂️.
Однако, есть и своеобразные плюсы в оцифровке второго издания словаря, которое было выпущено когда многие правила кыргызского языка еще не были закреплены, и потому, второе издание представляет из себя "слепок" языка того времени.

## Почему бы не AI?
Заманчивая идея просто закинуть словарь в LLM и сказать "промаркируй, пожалуйста" наталкивается на две проблемы:
1. Дорого.
2. Ошибки. Даже с самыми подробными промптами, LLM зачастую допускают кучу мелких ошибок, и каждый раз эти ошибки новые. А учитывая то, что сам словарь содержит много мелких отступлений от своей структуры, то во избежание регрессий, было принято решение упорядочить скриптами всё, что только можно, , а затем уже пройтись LLM-кой сверху.

# Описание структуры
В основном, используются 5 главных тегов
<k> – само слово
<meta> – дополнительная информация
<trn> – перевод слова или его определение
<ex> – пример употребления слова
